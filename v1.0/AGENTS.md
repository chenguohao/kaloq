# 正式版 1.0 开发规则

- 实施前读取 README.md、docs/README.md 和 docs/development-baseline.md。
- 正式版新代码在本目录；根 apps/ 和 scripts/ 是测试版/Demo 参考，不能混用构建入口、数据库或发布产物。
- 复用必须经过审查、迁入和验证，禁止依赖旧业务目录来绕过正式版约束。
- 初始化独立依赖、配置示例、数据库迁移及构建检查；不复制 Demo 数据、账号、密钥和生成产物。
- 正式数据库的迁移以 database/migrations/ 为唯一版本源，应用从该来源执行，禁止维护两份迁移正文。
- 根 AGENTS.md 中部署授权仍有效；发布前先完成正式来源与测试服务配置，不可盲用旧脚本。
