## 范围与使用规则

- 本轮为内部员工后台，商户由运营建档和代办；不包含商户自助登录。商户列表是运营入口，进入商户后处理订单及服务。
- 本轮目标为独立沙盒验收版，15 天结束不自动取得生产资金业务放行。按 11 月 4 日开工计算，15 个自然日到 11 月 18 日。
- 新增同类服务商不得要求停机重整存量数据；历史订单固定原服务商归属。具体数据、代码和发布要求以开发约束为准。
- 文档里的“建议”“待确认”“待联调”保留原状态，负责人必须补结论和证据。日期状态记录仅代表当时证据，不作为最新联调结果。
- 开发约束规定实现与验收方式；内部作业需求规定内部版业务范围；资金路径及对账签名方案规定资金控制。发现冲突先登记并解决，不自行放宽资金和权限要求。
- [基础功能清单](feature-list.md) 与 feature-list.tsv 保留作资金产品能力参考，其中旧商户自助页面和成员模式不扩入本轮；内部版页面、角色和功能以本目录内部版资料为准。
- 历史设计、商户版实现和沙盒联调记录保留在 ../../docs/v1/；通用架构提案保留在 [程序架构](../../docs/program-architecture.md)。它们是背景，不能替代本目录的现行约束。
- 正式代码在上级 v1.0/apps/，资料在本目录，统一由 [正式版入口](../README.md) 导航。后续正式资料统一在本目录修改。旧 v1 同名 Markdown 仅保留跳转，避免维护两套正文。
