# 内部版 V1 功能树

按「大模块 → 子模块 → 独立功能」展开为单张向右生长、纵向排列的树。每项功能单独一个节点；连线表示功能归属，不表示流程先后。

- **橙色 [P]**：调用 Pyvio。
- **绿色 [A]**：调用 Actyve。
- **深灰色**：Kaloq 自身功能。
- **＊**：待联调；接口参数或完整链路仍待验证。

本图只列平台功能。建群、线下人员分工和需求沟通属于系统外作业，不作为网站开发项。平台注册生成 Kaloq 商户 ID；Pyvio Unit／Client 是另行关联的通道标识。

已有 Demo 功能按第一版要求复用整合。拒绝后流转、审批人配置、大额门槛、冻结细则等仍沿用[规则草案](internal-v1-gap-and-plan.md)中的待确认状态，本图不改变确认结论。新增总池对账、个人签名和安全告警见[详细方案](reconciliation-and-execution-integrity.md)。
