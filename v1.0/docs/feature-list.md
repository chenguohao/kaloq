# 第一版 Feature List 与 Function List

> 2026-10-13。按已确认的资金路径整理，路径细节见 [法币与 U 的资金路径](fund-flow.md)。
>
> 商户只有一个美元钱包。收美元、提到银行卡都在 Pyvio。收 U、付 U 经过 Actyve 总池，完成后仍回到这个美元钱包。商户看不到 Actyve，也不持有 U 余额。
>
> 现在线上的工作台还是旧版：有 USDT 钱包和「划转 Convert」。那一版不作为第一版功能。

## Feature List

商户能完成的事。

| 编号 | Feature | 商户得到什么 |
|---|---|---|
| F1 | 开户 | 企业通过 Pyvio 认证，开出自己的美元账户 |
| F2 | 收美元 | 拿到银行 VA，别人电汇进来后，美元余额增加 |
| F3 | 提到自己的银行卡 | 把美元钱包里的钱提到本企业的银行卡 |
| F4 | 付给他人银行卡 | 把美元付给供应商或其他公司的银行卡 |
| F5 | 付 U | 用美元余额，把 USDT 打到对方已经在用的链上地址 |
| F6 | 收 U | 生成一笔临时收款，对方打入 USDT 后，变成自己的美元余额 |
| F7 | 余额与记录 | 看到可用美元、处理中金额，以及每一笔的状态 |
| F8 | 成员与权限 | 多人使用同一商户账户，权限按角色分开 |
| F9 | 接入 API | 自己的系统调用 Kaloq，不直接调用 Pyvio 或 Actyve |

第一版不做：

- 商户名下的 USDT 钱包，以及美元和 U 的自有划转
- 可以反复使用的长期 U 收款地址
- 虚拟卡、人民币结汇、美元以外的法币
